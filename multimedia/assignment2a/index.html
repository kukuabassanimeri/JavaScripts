Image Manipulation

Functionalities

1. Image Click to Enlarge
Clicking on the image toggles enlargement with a smooth zoom effect.

2. Left/Right Navigation Arrows
Allows users to navigate between multiple images in the popup view.

3. Zoom-In / Zoom-Out
Plus and minus icons enable zooming in and out on the enlarged image.

4. Mobile Responsiveness
The layout adjusts automatically on smaller screens; swipe gestures can be added.
